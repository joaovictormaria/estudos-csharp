# 📘 Estudos de C#

Repositório com os exercícios e atividades que fiz enquanto estudo **C#** e **Programação Orientada a Objetos**.

![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=csharp&logoColor=white)
![.NET](https://img.shields.io/badge/.NET_10-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)

## 📚 Conteúdos

| Tema | O que pratiquei |
|---|---|
| Construtores | Cadastro de funcionários, conta bancária e produtos |
| Sobrecarga | Vários construtores na mesma classe |
| Palavra `this` | Cadastro de empresa e de produtos |
| Encapsulamento | Propriedades, auto properties, personagem de RPG e cadastro de jogador |
| Sintaxe alternativa | Formas mais curtas de inicializar objetos |
| Exercício de fixação | Sistema simples de banco |
| Cadastros | Cadastro de produtos e de veículos |

## 📁 Estrutura

```
src/OlaMundo/
├── atividades/   # enunciados e resoluções das atividades
├── classes/      # classes usadas em cada tema
└── Program.cs    # ponto de entrada (escolha qual atividade rodar)
```

## ▶️ Como rodar

É preciso ter o [.NET 10 SDK](https://dotnet.microsoft.com/download) instalado.

```bash
git clone https://github.com/joaovictormaria/estudos-csharp.git
cd estudos-csharp
dotnet run --project src/OlaMundo
```

Para rodar outra atividade, troque a chamada dentro do `Main` em `src/OlaMundo/Program.cs`.
